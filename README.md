# Weather Modeling Using Quadratic Equation

This project predicts temperature using the quadratic formula:

T(t) = at² + bt + c

Where:
- T(t) is the predicted temperature at time t (e.g., hour/day).
- a, b, c are coefficients that can be modified to reflect environmental data.

### Versions
1. **Hardcoded Values** (`version1_hardcoded.py`): Uses predefined coefficients for the quadratic equation.
2. **Keyboard Input** (`version2_keyboard_input.py`): Takes user input for the coefficients and time.
3. **File Input (Single Set)** (`version3_file_input_single.py`): Reads coefficients and time from a file and calculates the temperature.
4. **File Input (Multiple Sets)** (`version4_file_input_multiple.py`): Reads multiple sets of coefficients and times from a file and calculates the temperatures.

### Files Included
- `inputs_single.txt`: Contains coefficients and time for a single set of inputs.
- `inputs_multiple.txt`: Contains multiple sets of inputs to calculate temperature for each set.
